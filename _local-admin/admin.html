Connect to GitHub

Create a fine-grained personal access token for the sottyon/nalaspackwalks repository with Contents: Read and write permission. The token is used only in this browser tab and is cleared when you close it.

  1. Create a fine-grained token and select only the nalaspackwalks repository.
  2. Under repository permissions, set Contents to Read and write, then generate the token.
  3. Paste the token below and connect. Never share the token with anyone.
